== 5. did Jod ever run the done-when command itself?
==============================================================
-- a done-when with an observable side effect: if Jod runs it, the file appears --
$ jod goal add sideeffect say OK and stop --done-when touch /tmp/jod-e2e/donewhen/RAN_BY_JOD
sideeffect is running

$ rm -f /tmp/jod-e2e/donewhen/RAN_BY_JOD

$ jod daemon --once
[jod/daemon] reloaded 4 prior run(s)
claimed 2 · started 2 · held 0 · failed 0

$ (waiting for every run to reach a terminal status)
settled after 20s

$ ls -la /tmp/jod-e2e/donewhen/RAN_BY_JOD 2>&1 || echo 'the file does not exist: Jod never executed the check'
