==============================================================
== 2. start the daemon
==============================================================

==============================================================
== 3. revoke it. The device is compromised; this is the emergency lever.
==============================================================
$ jod-api token revoke victim

$ jod-api token list
no tokens issued

-- the token store no longer contains it. Does the daemon care? --
$ try 'after revoke, daemon still running' 'jod_36a99eb9f78b7bc20b3a37acd602128b7035a188a6ed5139860d1616801444ab'
after revoke, daemon still running: HTTP 200
